What changed when controls were removed

The unchecked application adapter records synthetic acceptance. It is not a real bank backend or an unguarded Qwen agent. Direct I/O bypasses FinGuard in every mode. Plain Docker remains around the non-OpenShell baselines. Counts are repeated fixtures, not independent random samples.

An application rejection prevents execution: there is no downstream OpenShell denial to claim for that call. Study 2 / 300 trials

Model-Driven Adversarial Evaluation

How often does the model propose prohibited actions, and what happens when it does? 40 injection prompts × 5 runs, 10 benign tasks × 5 runs, and 10 multi-turn sequences × 5 runs. The local model uses temperature 0.6 and recorded seeds. These trusted-host tests exercise FinGuard’s production tool controls; OpenShell’s direct-I/O evidence remains a separate experiment.

Model behavior vs. system enforcement

Observed results from this bounded experiment, not estimates of universal agent safety. The outside cards count adversarial trials; the middle card counts prohibited proposals.
