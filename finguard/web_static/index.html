        What changed when controls were removed

        The unchecked application adapter records synthetic acceptance. It is not a real bank backend or an unguarded Qwen agent. Direct I/O bypasses FinGuard in every mode. Plain Docker remains around the non-OpenShell baselines. Counts are repeated fixtures, not independent random samples.

        Model-driven injection trials

        An application rejection prevents execution: there is no downstream OpenShell denial to claim for that call. Filesystem rows cite OS errors; native OCSF links are attached only to observed network events. A single-continuation model trial is not a complete investigation or a general prompt-injection benchmark.
